# Aetheria PmheeAether Bot (Auto-Injector & Packet Automation)

High-performance Packet-based automation bot and Auto-Injector for **Aetheria Online (Windows Desktop App)**.

## Features
- **100% Packet-Driven**: Ammo counting, real-time arrow deduction, buying & selling, warping, and NPC interaction via WebSocket MessagePack.
- **Auto-Injector for Desktop EXE**: Injects directly into `Aetheria Online.exe` on startup. No DevTools or copy-pasting required.
- **GitHub Auto-Update**: Checks GitHub on startup for the latest `bot.js` payload with automatic offline local fallback.
- **Hot-Reload**: Press `F5` in-game anytime to reload code modifications instantly.
- **Deep Equipment & Inventory Sniffer**: Built-in sniffer tools to capture exact equip packets.

## Quick Installation
1. Close `Aetheria Online.exe`.
2. Double-click `install_patch.bat`.
3. Open `Aetheria Online.exe` and enjoy!

## Uninstallation
Double-click `uninstall_patch.bat` to restore the original unmodified launcher.
