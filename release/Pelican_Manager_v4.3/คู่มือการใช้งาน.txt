================================================================================
          PELICAN CONTROL HUB — AETHERIA ONLINE AUTOMATION SUITE v4.3
================================================================================

ยินดีต้อนรับสู่ Pelican Control Hub ระบบบริหารจัดการ Multi-Client, ออกแบบแผนการเล่น
(Plan Script) และระบบควบคุมบอทอัตโนมัติระดับมืออาชีพสำหรับเกม Aetheria Online


--------------------------------------------------------------------------------
 1. สิ่งที่มีมาให้ในชุดติดตั้งนี้
--------------------------------------------------------------------------------
 - PelicanManager.exe : โปรแกรมรันหลักแบบ Native Windows พร้อมถาดระบบ (System Tray)
 - pelican.ico        : ไอคอนโปรแกรมความละเอียดสูง
 - bin/node.exe       : ระบบรันไทม์ Portable แบบสมบูรณ์ ไม่จำเป็นต้องติดตั้งโปรแกรมเสริมใดๆ
 - manager/           : ระบบเซิร์ฟเวอร์ควบคุม Dashboard, Multi-Client และ Plan Script
 - bot.js             : สคริปต์บอท Pelican Engine เวอร์ชันล่าสุด
 - main.js            : โมดูลเชื่อมต่อระบบเกม (Game Loader)
 - Start_Pelican.bat  : ไฟล์เปิดโปรแกรมสำรองในโหมดแสดงหน้าต่าง Console (สำหรับตรวจเช็กข้อความ)


--------------------------------------------------------------------------------
 2. วิธีเริ่มใช้งานใน 3 ขั้นตอนง่ายๆ
--------------------------------------------------------------------------------

[ขั้นตอนที่ 1] เปิดโปรแกรม
  - ดับเบิ้ลคลิกที่ไฟล์ "PelicanManager.exe"
  - โปรแกรมจะทำงานทันที พร้อมแสดงไอคอนรูป Pelican สีฟ้า-ทอง ใน System Tray (มุมขวาล่างข้างนาฬิกา)
  - หน้าต่าง Dashboard ควบคุมจะเปิดขึ้นในเว็บเบราว์เซอร์ของคุณโดยอัตโนมัติ (http://localhost:3888)

[ขั้นตอนที่ 2] ติดตั้ง/อัปเดตสคริปต์ลงตัวเกม (ทำเพียงครั้งแรก หรือเมื่อมีการอัปเดตบอท)
  - ในหน้าต่างเบราว์เซอร์ ให้คลิกที่เมนู "Game Patcher" ด้านบน
  - ระบบจะค้นหาโฟลเดอร์ติดตั้งของเกม Aetheria Online ให้โดยอัตโนมัติ
  - กดปุ่ม "⚡ ติดตั้ง/อัปเดตสคริปต์ลงเกมทันที"
  - เมื่อขึ้นสถานะสีเขียวว่าติดตั้งสำเร็จ ตัวเกมจะพร้อมเชื่อมต่อกับ Pelican Control Hub ทันที!

[ขั้นตอนที่ 3] เปิดเกมและเริ่มใช้งาน
  - กลับมาที่หน้า "Dashboard"
  - กดปุ่ม "🚀 เปิดทุกจอ (Launch All)" หรือกดเปิดเฉพาะจอที่ต้องการ
  - ตัวเกมจะเปิดขึ้นมาพร้อมฝังแถบ Pelican Assistant ในเกมโดยอัตโนมัติ


--------------------------------------------------------------------------------
 3. ฟังก์ชันเด่นในเวอร์ชัน 4.3 (New Features)
--------------------------------------------------------------------------------

★ ระบบเปลี่ยนอาชีพในตัว (Built-in Auto Job Change)
  - ไม่ต้องตั้งค่า Trigger หรือโหนดเดินกลับเมืองเองให้ยุ่งยากอีกต่อไป!
  - ในหน้าต่างแก้ไขแผน (Plan Script Editor) จะมีช่องให้เลือก:
      * Class 1 (Job 10): เลือกอาชีพที่ต้องการเปลี่ยนตอนเป็น Novice เช่น Archer, Swordsman ฯลฯ
      * Class 2 (Job 50): เลือกอาชีพขั้นสูง เช่น Hunter, Bard, Dancer, Knight ฯลฯ
  - เมื่อตัวละครเก็บ Job ถึงเกณฑ์ บอทจะเดินกลับเมือง Solhaven ไปคุยกับ Valkyrie (n5) 
    และเปลี่ยนอาชีพให้อัตโนมัติ จากนั้นจะจำสถานะไว้เพื่อไม่ให้ทำซ้ำ

★ ระบบจัดคิวอัปสกิลตามลำดับพ้อยต์ (Sequential Skill Allocation Queue)
  - กดคลิกสกิลตามลำดับที่ต้องการให้อัป บอทจะเรียงเป็นคิว 1, 2, 3...
  - เมื่อเลเวลอัปและได้รับ Skill Point ในเกม บอทจะทะยอยอัปให้ตามคิวทันที

★ ระบบอัปสเตตัสอัตโนมัติตามเป้าหมาย (Auto Stat Priority)
  - กำหนดค่าเป้าหมายของแต่ละค่าสเตตัส (STR, AGI, VIT, INT, DEX, LUK)
  - ระบบจะเฉลี่ยและอัปสเตตัสให้ทันทีเมื่อมี Status Points คงเหลือ

★ การควบคุมผ่านถาดระบบ (System Tray)
  - คลิกขวาที่ไอคอน Pelican มุมขวาล่างของจอเพื่อ:
      * เปิดหน้าต่าง Dashboard ทันที
      * กด "📌 สร้างทางลัดบน Desktop" เพื่อสร้างไอคอนสวยงามไว้บนหน้าจอเดสก์ท็อป
      * สั่งรีสตาร์ทเซิร์ฟเวอร์ หรือปิดโปรแกรมอย่างปลอดภัย


--------------------------------------------------------------------------------
 4. การแก้ปัญหาเบื้องต้น (Troubleshooting)
--------------------------------------------------------------------------------
 - หากเปิดเกมแล้วหน้าต่างบอทไม่ปรากฏ:
     -> เข้าหน้า Game Patcher แล้วกดติดตั้งสคริปต์ใหม่อีกครั้ง จากนั้นปิดเกมแล้วเปิดใหม่ผ่านตัว Hub
 - หากต้องการย้ายไปเครื่องอื่น:
     -> สามารถ Copy ทั้งโฟลเดอร์นี้ไปเปิดที่เครื่องอื่นได้ทันทีโดยไม่ต้องติดตั้งโปรแกรมเสริมใดๆ
