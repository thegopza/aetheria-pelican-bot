# สวิตช์ระบบหนี้ในแอดมิน

สถานะ: ส่วนของ owner-host / friends-offline ที่ยังไม่เปิด production ไม่ใช่สวิตช์ของ Worker รุ่นปัจจุบัน

- หน้า `/v1/aetheria/admin/usage/machines/ui` แสดงสถานะและปุ่มเปิด/ปิดระบบหนี้ ใช้สิทธิ์ Cloudflare Access ของเจ้าของเดิม
- ปิดแล้วหยุดสร้างหนี้ใหม่ ไม่ลบหนี้เก่า ไม่หยุดการส่งหนี้ค้าง การเติมเงิน payload หรือการแก้คำถาม
- เก็บประวัติการเปลี่ยนสถานะและเวลาที่มีผลในฐานกลาง ตรวจเหตุการณ์ย้อนหลังตามเวลาการใช้งาน เพื่อไม่หักเงินช่วงที่ปิดระบบแม้เครื่องผู้ใช้ยังออฟไลน์
- Manager เก็บสถานะล่าสุดในแฟ้มหนี้เข้ารหัส รับสถานะใหม่จากการ sync เครื่องละประมาณหนึ่งนาทีเมื่อเชื่อมต่อได้ และเว้นระยะเมื่อเชื่อมต่อไม่ได้
- ตอนเจ้าของออฟไลน์ Manager ใช้สถานะล่าสุดจนเชื่อมต่อกลับมา สวิตช์ไม่ได้สั่งเปลี่ยนเครื่องที่ไม่มีการเชื่อมต่อทันที
- การเปิดอีกครั้งคิดรายจอ/วันตามอัตราเดิมและกติกาไม่คิดซ้ำ โดยหนี้ก่อนปิดยังอยู่
- revision ของสวิตช์แยกจาก revision ของยอดเงิน ACK เก่าต้องไม่เปลี่ยนสวิตช์หรือยอดใหม่กลับไปเป็นค่าเก่า

ก่อนปล่อย: ทดสอบสิทธิ์แอดมิน/คำขอข้ามเว็บ, เปิดปิดและคำขอซ้ำ, หนี้ย้อนหลังผ่านช่วงปิด, ACK มาช้า, restart/offline/reconnect, payload และยอดเติมเงิน และตรวจภาพหน้าแอดมินจริง ห้ามเปิดบริการฐานเก่าหรือเปลี่ยน route ก่อน cutover ผ่านการตรวจ

ผลตรวจ 2026-10-13: Manager 145/145 ผ่าน; private debt/offline/cutover + Cloudflare billing 36/36 ผ่าน; หน้าแอดมินจริง Edge/Chrome 8/8 ผ่านและตรวจภาพแล้ว ครอบคลุม protocol1 เดิมบน owner-host ผ่าน hook เฉพาะ owner-host; ไม่เปิด hook หรือเปลี่ยน flags ของ production Worker

ชุดโค้ด friends-offline เดิมและสวิตช์ยังเป็น candidate ใน working tree ตามข้อกำหนดห้ามปล่อยก่อนผ่าน cutover ส่วนเอกสารและการปรับชุดทดสอบของ hotfix เดิมสามารถแยก commit ได้โดยไม่เผยแพร่ candidate หรือแตะข้อมูลลูกค้า
